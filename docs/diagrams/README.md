# Diagrams

Committed Excalidraw sources and rendered PNGs for the README and docs.

Drawing rules (from the [NixOS `excalidraw` agent skill](https://github.com/wesbragagt/nixos/blob/main/home/skills/excalidraw/SKILL.md)):

- Hand-drawn style (`roughness: 2`), Excalifont (`fontFamily: 1`).
- Dark canvas `#1e1e2e`, pastel/dark fills from the documented palette.
- 1200×900 (4:3) content area; titles 28, labels 20 (auto-shrunk to ≥14 to fit),
  body 16; shapes ≥120×60; 20–30px gaps.
- Z-order: background → zone → shape → its text → arrows → labels.
- No emoji; keep text short and readable.

The installed official CLI only renders standard scene JSON (it does not expand
the skill's `label`/`cameraUpdate` shorthand), so the scenes are generated by
`build_scenes.py` and rendered with `render.sh`.

```bash
# if needed: nix shell nixpkgs#excalidraw-cli
./render.sh
```

Sources:

- `architecture.excalidraw` — system context, edge/cloud components.
- `firmware-dataflow.excalidraw` — wake cycle, OTA, fault hooks.
- `demo-topology.excalidraw` — host + compose stack.
- `ota-flow.excalidraw` — publisher → broker → device → flash → MCUboot.
